# Changelog

## 0.1.0

- First release: the artifact path builders from `@mulmoclaude/core/artifacts` —
  `ARTIFACTS_ROOT`, `slugifyArtifact`, `yearMonthUtc`, `buildArtifactRelPath`,
  `toWorkspaceArtifactPath` and `hasUnsafePathSegment` — so a plugin here can name the files it
  writes under `files.artifacts` without depending on MulmoClaude.
